# Retail Data Entry React App

This project converts the original HTML/CSS/JavaScript retail data entry form into a React app.

## Run locally

Install Node.js first if `node` or `npm` is not available in PowerShell.

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Demo login

- Username: `admin`
- Password: `12345`

## Features

- React state-based login and dashboard
- Retail entry form with validation
- Custom weather condition modal
- Local storage persistence
- Summary statistics
- Search and purchase-status filtering
- Delete records
- CSV export
